# TAU Support — agent docs

AI-powered support assistant for TAU staff and students.

Monorepo-wide workspace docs live in the repo root: `agents/workspace/`.

## Convention

After changing tool behavior, update the matching doc in this folder so it stays the source of truth for this app.

Suggested files to add as the tool grows:
- `mvp-spec.md` — requirements and scope
- `phase-flows.md` — user flows and state transitions
